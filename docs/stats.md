# 路徑 / 軌跡統計 (Stats)

本文件定義統計畫面的數據項, 計算規則與版面. 實作: `core/stats/TraceStats.kt` (模型),
`core/stats/TraceStatsCalculator.kt` (計算), `feature/stats/StatsScreen.kt` (畫面),
`feature/stats/ElevationProfileChart.kt` (剖面圖繪製 + 互動 + PNG 匯出),
`feature/stats/ChartViewport.kt` (縮放 / 平移的視窗數學), 入口接線在 `MainActivity`.

## 1. 入口

- **路徑檢視模式** 動作列: 編輯, **統計**, 匯出 GPX, 離開.
- **軌跡檢視子模式** 動作列: 繼續錄製, **統計**, 匯出 GPX, 離開.
- **載入清單** (規劃路徑與軌跡) 每列 "更多" 選單: **統計**, 改名, 匯出 GPX, 刪除.
  由清單開啟時先關閉清單對話框 (overlay 蓋不住 dialog window), 再讀檔計算.

統計畫面是全螢幕 overlay, 蓋在地圖與所有控制之上; 系統返回鍵與 "關閉" 皆回到開啟前的所在模式.
計算於背景執行, 完成前畫面顯示載入指示.

## 2. 數據項

| 項目 | plan | track | 來源 |
|---|---|---|---|
| 距離 | v | v | 相鄰點 vincenty 距離加總 |
| 總時間 / 移動時間 / 停止時間 | | v | `pt` 時間戳 (見 §3.2) |
| 均速 / 移動均速 / 最大速度 | | v | 距離與時間衍生 |
| 累計爬升 / 累計下降 | v | v | DEM 重取樣 + 遲滯 (見 §3.1) |
| 最高 / 最低海拔 | v | v | DEM 重取樣序列的極值 |
| 開始 / 結束時刻 | | v | 首末 `pt` 的 `t` |

高度一律依 trace_spec.md §8 由 DEM 於使用時查得, 不採檔內存值; DEM 缺失時海拔類項目顯示
"-", 剖面圖顯示無資料佔位.

## 3. 計算規則 (`TraceStatsCalculator`)

### 3.1 高程: 重取樣 + 遲滯

- 沿攤平折線每 `SlopeScale.SAMPLE_SPACING_M` (30 m) 重取樣查 DEM (另補確切終點),
  與地圖路徑線的坡度取樣一致; 逐 GPS 點直接累加會把取樣雜訊全數累進爬升值.
- 爬升 / 下降採**遲滯累加**: 與基準點高差達 `HYSTERESIS_M` (10 m) 才累計並移動基準,
  未達門檻的來回起伏不計. 單調爬升因此最多低估一個門檻值, 為此法的已知性質.
- 最高 / 最低海拔取重取樣序列 (未填補的原始查值) 的極值.
- 坡度 (供剖面圖上色) 以中央差分計算, DEM 空洞先以鄰值持平填補, 與
  `PlannedRouteLayer.sampleSlopes` 同法; 分級與顏色共用 `core/elevation/SlopeScale`.

### 3.2 時間: 移動 / 停止判定

- 逐段 (相鄰兩點) 計算段速 = 段距 / 段時. 段速 >= `MOVING_SPEED_MPS` (0.3 m/s) 的段計入
  移動時間; 停止時間 = 總時間 - 移動時間.
- 均速 = 距離 / 總時間; 移動均速 = 距離 / 移動時間; 最大速度 = 單段段速最大值.
- 錄製時 gating (docs/gating.md) 已濾除離群定位, 故不再另做速度平滑; 若實測仍見尖峰,
  再議平滑窗.

## 4. 剖面圖互動: 縮放 / 平移 / 十字游標

`ElevationProfileChart` 除了畫圖之外還處理手勢, 狀態存於畫面內 (不落地, 離開統計畫面即重置):

- **視窗 (viewport)**: 目前可見的距離範圍 `[startM, endM]` (`ChartViewport`), 初始值與最小縮放皆為
  全長. 最小可見範圍為 300 公尺; 全長 <= 300 公尺的路徑 / 軌跡等同不可縮放.
- **雙指縮放 / 平移**: 雙指捏合以兩指質心 (centroid) 對應的距離為錨點縮放 X 軸; 雙指質心的水平位移
  平移視窗. 兩者皆會裁切在 `[0, totalM]` 內, 不會使視窗反轉或超出路徑範圍. Y 軸永遠依目前可見範圍的
  海拔自動調整 (含既有的 "退化範圍下限展開至 50 m" 規則, 以及下述垂直誇張上限); 格線與座標標籤隨可見
  範圍重新計算, 公里標籤的小數位數會隨縮放層級增加, 確保相鄰刻度不會顯示相同文字. 曲線 (折線與曲線下
  填色) 一律裁切在繪圖區矩形內, 可見範圍外的樣本不會畫到座標軸與標籤區上.
- **垂直誇張上限**: 剖面圖本質上有垂直誇張 (依真實比例的登山剖面近乎水平線), 但無上限時, 長距離小落差
  的路徑會被畫成一排針山. `ChartLayout.compute` 依繪圖區像素尺寸與可見距離範圍計算垂直誇張倍率, 超過
  `MAX_VERTICAL_EXAGGERATION` (25) 時**只向上**擴大海拔範圍 (曲線保持貼在其實際最低海拔上, 上方留白).
  典型登山路線遠低於此上限, 不受影響; 縮放時依可見範圍重新計算, 上限同樣生效. 倍率不顯示於畫面上
  (曾實作右上角倍率標籤, 使用者裁示移除).
- **單指點選 / 拖曳 (十字游標)**: 單指永遠只用來拖曳十字游標, 不會平移視窗 (與雙指手勢互斥, 由
  `ElevationProfileChart` 內一個自寫的手勢迴圈依當前觸點數量分流, 而非用標準的
  `detectTransformGestures`/`detectDragGestures`, 因為那兩者預設會把單指也當成平移). 選中的樣本以
  垂直線 (貫穿繪圖區) + 水平線 (該樣本海拔) + 實心圓點標示.
  - 游標依樣本的 `distanceM` 錨定, 而非依畫面像素位置, 因此縮放 / 平移時游標仍指向同一樣本; 若該樣本
    捲出目前可見範圍, 十字線與圓點不繪出, 但資訊面板保留直到使用者關閉.
  - 資訊面板 (繪圖區左上角的半透明圓角小面板) 顯示: 距離 (< 1 km 顯示公尺, 否則公里到小數兩位),
    海拔 (四捨五入到整數公尺, 無資料顯示 "-"), 坡度 (`tan(坡度角) * 100` 四捨五入到整數百分比, 帶正負
    號, 無海拔資料顯示 "-"), 時間 (樣本 `epochMs` 的本地 `HH:mm:ss`; 規劃路徑或無時間戳的樣本直接省略
    此欄, 不顯示 "-"). 面板右側有 "×" 可關閉游標.
- **PNG 匯出不受目前縮放 / 游標影響**: 匯出一律用全長, 不含游標, 見 §6.

## 5. 高程剖面樣本的時間戳 (`epochMs`)

`TraceStats.ProfileSample.epochMs` 由 `TraceStatsCalculator.buildProfile` 依累計距離對點的
`timesMs` 線性內插得出 (與距離內插用同一套找區間邏輯: 找到 `cumulative[i-1] <= d <= cumulative[i]`
的區間, 依相同比例內插 `timesMs[i-1]..timesMs[i]`). 僅當來源 `timesMs` 非 null 且長度與點數相同時才
計算 (與 `computeTime` 的有效性判定相同); 規劃路徑沒有時間戳, 因此其樣本 `epochMs` 一律為 null.

## 6. PNG 匯出

- 入口: 統計畫面頂列, 關閉鈕左側的 "匯出 PNG" (`Icons.Filled.SaveAlt`), 僅在剖面圖有可畫資料
  (`stats` 非 null 且至少一筆樣本有海拔) 時顯示.
- 只匯出剖面圖本身 (不含下方數據格), 永遠以**全長** (忽略目前縮放) 且**不含十字游標**繪製.
- 畫面上的互動版與匯出版共用同一套繪製函式 (`drawProfileChart`), 避免兩份重複的繪圖邏輯; 差異只在
  呼叫端傳入的可見範圍 (全長 vs 目前視窗) 與是否疊加游標.
- 匯出走離屏 (offscreen) 算圖: 固定 2048x1152 px, 以 `CanvasDrawScope` 繪入 `ImageBitmap`, 背景用主題
  `surface` 色鋪滿 (不透明), 圖表配色與畫面上完全一致, 並在頂端加畫路徑 / 軌跡名稱作為標題. 完成後以
  `asAndroidBitmap()` 轉為 `Bitmap` 並壓縮成 PNG.
- 儲存流程比照既有 GPX 匯出: SAF `ACTION_CREATE_DOCUMENT` (`image/png`), 預設指向下載目錄, 建議檔名
  為 "<名稱>.png" (與 GPX 匯出相同的檔名消毒規則, 把 `/` 換成 `-`). 實際算圖與壓縮皆在背景執行緒進行,
  不卡主執行緒. 成功顯示 snackbar "已匯出 ...", 失敗則盡力刪除半寫入的檔案並跳出封鎖式錯誤對話框
  (資料未落地屬於使用者不可錯過的錯誤, 依 CLAUDE.md 訊息載體慣例不可用 snackbar). 使用者取消挑選器
  則無聲返回.

## 7. 版面 (直 / 橫向)

- **直向**: 頂列 (名稱 + 關閉) 之下, 高程剖面圖固定為寬矮版面 - 高度取
  `min(螢幕寬 x 0.6, 螢幕高 x 0.5)` - 其餘高度全給兩欄數據格 (超出才捲動). 剖面圖不再吃滿
  剩餘高度: 直向高瘦的繪圖區會把垂直誇張推到極端 (見 §4 垂直誇張上限), 寬矮版面亦為各地圖
  App 剖面圖的通例.
- **橫向**: 剖面圖改佔左側約 58% 寬且吃滿高度 (X 軸是距離, 寬度是剖面圖最需要的資源),
  數據格移至右側兩欄, 獨立捲動.
- 兩種排版重用同一組 composable (`ElevationProfileChart` + 數據格), 僅切換排列容器.
- 剖面圖: X = 距離 (km), Y = DEM 海拔 (m), 折線依坡度分級上色 (同地圖路徑線的五色, 線寬 3 dp),
  曲線下鋪半透明面; DEM 無資料的樣本讓折線中斷.

## 8. 已知限制 / 待議

- 最高 / 最低海拔取自 30 m 重取樣, 與真實極值可有一個樣距內的誤差.
- 遲滯門檻 10 m 與移動門檻 0.3 m/s 為首版定值, 待實測校準.
- 錄製中的即時統計為另一項待辦 (見 CLAUDE.md), 不在本畫面範圍.
- 剖面圖互動 (縮放 / 平移 / 十字游標) 與 PNG 匯出待實機驗證手感與效能.
