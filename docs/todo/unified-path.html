路徑合一計劃書

最後更新: 2026-10-13. 工作分支: unifmt.

1. 目的

  1. 規劃路徑與軌跡合為單一種路徑. 檔案只有一種, 清單只有一份, 檢視畫面只有一種.
  2. 所有路徑預設以實線顯示, 以顏色區分錄製中軌跡, 軌跡與規劃路徑.
  3. 所有路徑皆支援坡度顯示與里程標記, 兩者各以一個按鍵切換.
  4. 已存路徑的開啟, 改名, 刪除, 匯出, 統計, 複製與匯入集中於單一的檔案管理畫面.

設計取捨一律以登山者的操作體驗為判準, 工程量不列入考量.

2. 定義

規劃路徑由航點 (waypoint) 與相鄰航點之間的路段 (segment) 構成的路徑, 沒有時間. 來源為規劃, 匯入或自軌跡複製.

4. 行為規格

4.1 路徑檔與種類判定

  1. 所有路徑檔存於路徑資料夾. 錄製暫存檔亦存於此, 檔名為 .recording-<開始時刻毫秒>.jsonl.
  2. 路徑檔檔名規則不變, 為 <名稱轉換後的字串>-<建立時刻毫秒>.jsonl.
  3. 檔頭含格式版本 v, 名稱 name, 建立時刻 createdAt, 產生程式 app, 以及選用的 appVersion. 新寫入的檔頭版本為 2, 不含種類欄位 type.
  4. 讀取時接受版本 1 與版本 2. 檔頭若有 type 欄位, 一律忽略.
  5. 紀錄的型別與欄位不變. 規劃路徑以航點紀錄 wpt 與路段紀錄 seg 表示, 軌跡以定位點紀錄 pt 表示.

種類依下表判定:

檔案內容種類
含至少一筆 seg 紀錄規劃路徑
不含 seg 紀錄, 且含至少一筆 pt 紀錄軌跡
兩者皆無無效檔, 不列入清單

每一筆 pt 紀錄皆含時間欄位 t (已讀證, 解析程式將其視為必要欄位), 故軌跡的每一點皆有時間.

4.2 名稱規則

  1. 名稱不得與清單內任何其他路徑相同, 不分種類. 比對方式為去除頭尾空白後完全相同.
  2. 此規則適用於儲存新規劃, 儲存錄製, 匯入, 改名與 "複製為規劃路徑".
  3. 編輯既有規劃路徑後儲存, 以及繼續錄製後儲存, 比對時排除該路徑自身.
  4. 名稱留空時一律採用 "未命名路徑".
  5. 舊資料夾搬入的檔案不改名. 搬入後若有兩條路徑同名, 兩者並存.

4.3 舊資料夾的搬移

  1. 搬移於儲存層每次被存取時執行, 舊資料夾皆不存在時立即結束. 搬移對每個檔案獨立進行.
  2. 舊資料夾內每個副檔名為 .jsonl 且非錄製暫存檔的檔案, 依序執行下列步驟: 將內容逐位元組複製為路徑資料夾內的同名暫時檔, 將暫時檔改名為正式檔名, 刪除舊資料夾內的原檔.
  3. 路徑資料夾內已有同名檔案時, 原檔留在舊資料夾, 不覆寫任何檔案.
  4. 任一步驟失敗時 (包含尚未取得儲存權限而無法讀寫的情形) 刪除暫時檔, 原檔留在舊資料夾, 於下次存取時重試.
  5. 舊資料夾內殘留的錄製暫存檔直接刪除, 與現行對殘留暫存檔的清理規則一致.
  6. 舊資料夾清空後即刪除該資料夾.
  7. 清單同時列出路徑資料夾與尚存的舊資料夾內的路徑檔, 故任何路徑檔皆不會因搬移失敗而自清單消失.

搬移採用複製後刪除, 只依賴現行程式已在此儲存區使用的讀檔, 寫檔, 同資料夾改名與刪除四種操作 (已讀證). 清單顯示的日期取自檔頭的建立時刻, 故搬移後名稱與日期不變.

4.5 檔案管理畫面

檔案管理畫面為全螢幕畫面, 覆蓋地圖與所有按鍵, 覆蓋方式與統計畫面相同. 此畫面只由地圖狀態的 "檔案" 按鍵開啟.

  1. 頂端列由左至右為標題 "檔案管理", 文字按鍵 "匯入 GPX", 關閉圖示. 關閉圖示的位置與樣式與統計畫面相同.
  2. 按下關閉圖示或系統返回鍵即關閉此畫面, 回到地圖狀態.
  3. 頂端列下方為路徑清單, 佔滿其餘畫面並可捲動. 路徑依建立時刻由新至舊排列, 不分種類.
  4. 每一列由左至右為種類色圓點 (直徑 12 dp), 名稱與其下方的 "日期 - 距離", 以及 "更多" 選單. 軌跡的圓點為藍色, 規劃路徑的圓點為綠色.
  5. "更多" 選單的項目依序為 "統計", "改名", "匯出 GPX", "複製為規劃路徑", "刪除". "複製為規劃路徑" 只出現於軌跡.
  6. 清單為空時顯示 "尚無已儲存的路徑".

4.6 開啟與顯示

  1. 開啟一條路徑後, 該路徑加入地圖, 地圖視野調整為涵蓋整條路徑, 並進入檢視狀態, 以該路徑為焦點路徑.
  2. 已開啟的路徑再次被開啟時不重複加入, 只重新成為焦點路徑並調整視野.
  3. 已開啟路徑的數量不設上限.
  4. 已開啟路徑於離開檢視狀態, 進入編輯狀態, 開始錄製後皆維持顯示.
  5. 自地圖移除已開啟路徑的手段有兩種, 分別為地圖狀態的 "清除" (移除全部), 以及於檔案管理畫面刪除該路徑 (只移除該條).

4.8 編輯, 錄製, 匯入與複製

編輯狀態的按鍵列 ("+", "−", "儲存", "取消") 與航點操作規則不變. 匯入而來的路段仍不可用 "−" 移除.

操作結果
於檢視狀態按 "編輯"焦點路徑暫時離開已開啟路徑, 改由編輯畫面繪製. 其他已開啟路徑維持顯示.
新規劃按 "儲存"詢問名稱後存檔. 存檔後的路徑成為已開啟路徑與焦點路徑, 進入檢視狀態.
既有規劃路徑編輯後按 "儲存"覆蓋原路徑 (寫入新檔後刪除原路徑檔). 存檔後的路徑成為焦點路徑, 進入檢視狀態.
新規劃按 "取消"回到地圖狀態, 不新增任何路徑.
既有規劃路徑編輯後按 "取消"編輯前的路徑回到已開啟路徑並成為焦點路徑, 進入檢視狀態.
按 "繼續錄製"焦點路徑離開已開啟路徑, 其全部定位點成為錄製中軌跡的開頭. 其他已開啟路徑維持顯示.
錄製後按 "儲存"詢問名稱後存檔. 存檔後的軌跡成為已開啟路徑與焦點路徑, 進入檢視狀態.
新錄製按 "放棄" 並確認回到地圖狀態. 已開啟路徑不受影響.
繼續錄製後按 "放棄" 並確認只丟棄本次新增的定位點. 原軌跡重新成為已開啟路徑與焦點路徑, 進入檢視狀態.

錄製服務, 定位點寫入前的篩選規則, 錄製中與已停止的按鍵列, 以及放棄錄製的確認對話框文字維持不變. 理由為本計劃只變更儲存位置, 顯示方式與路徑的開啟方式.

匯入 GPX 的規則如下:

  1. 入口有兩處, 分別為檔案管理畫面的 "匯入 GPX" 按鍵, 以及自其他 App 開啟 .gpx 檔.
  2. 檔內每一點皆有時間時, 匯入為軌跡. 保留全部的點與時間, 不抽稀 (simplification), 建立時刻取最早一點的時間.
  3. 其餘情形匯入為規劃路徑. 捨棄時間, 各段以 3 公尺容差抽稀, 並標記為匯入路段.
  4. 命名對話框標題為 "匯入 GPX", 只有名稱欄位, 預填檔內名稱, 檔內無名稱時預填檔名. 按鍵為 "匯入" 與 "取消".
  5. 存檔後的路徑成為已開啟路徑與焦點路徑, 進入檢視狀態, 並以限時訊息顯示 "已匯入路徑: <名稱>". 檔案管理畫面開啟中時一併關閉.
  6. 名稱重複時重新開啟命名對話框, 保留已輸入的名稱.
  7. 檔內沒有任何點時, 以錯誤對話框顯示現行訊息. 編輯狀態下自其他 App 開啟 .gpx 檔時, 以現行的限時訊息拒絕.

"複製為規劃路徑" 的規則如下:

  1. 命名對話框標題為 "複製為規劃路徑", 名稱欄位預填 "<原名稱> 規劃". 按鍵為 "複製" 與 "取消".
  2. 新的規劃路徑由該軌跡的全部定位點構成單一匯入路段, 以 3 公尺容差抽稀, 捨棄時間. 建立時刻為複製當下.
  3. 複製後檔案管理畫面維持開啟, 清單重新整理, 並以限時訊息顯示 "已複製為規劃路徑: <名稱>". 原軌跡不受影響, 地圖不變.

4.10 坡度開關與里程開關

  1. 右下角由上而下依序為里程開關, 坡度開關, "回到目前位置" 按鍵. 三者皆為小型圓形按鍵, 間距與現行右下角按鍵欄相同.
  2. 里程開關的圖示為 Icons.Filled.Straighten, 無障礙說明文字為 "里程標記". 坡度開關的圖示為 Icons.Filled.Terrain, 無障礙說明文字為 "坡度顯示". 兩個圖示皆存在於專案現用的圖示套件 (已讀證).
  3. 按一下即切換, 地圖上所有路徑同時改變. 開啟時按鍵底色為主題主色, 與左上角 "?" 按鍵開啟時相同. 關閉時為預設底色.
  4. 地圖上至少有一條路徑時顯示兩個開關. 路徑包含已開啟路徑, 編輯中的規劃路徑與錄製中軌跡. 地圖上沒有路徑時兩個開關皆不顯示.
  5. 編輯狀態下 "回到目前位置" 按鍵依現行規則隱藏, 兩個開關仍顯示. 符號辨識模式下整欄依現行規則隱藏.
  6. 坡度開關首次使用時為關閉, 里程開關首次使用時為開啟. 兩者的狀態寫入裝置, 下次啟動時沿用.
  7. 高程資料夾不存在時, 按下坡度開關只顯示限時訊息 "未安裝高程資料, 無法顯示坡度", 開關維持關閉. 啟動時若保存的狀態為開啟而高程資料夾不存在, 視為關閉.
  8. 小螢幕上右下角按鍵欄與左下角按鍵列重疊時, 整欄依現行規則上移至按鍵列上方.

4.11 統計與 GPX 匯出

  1. 統計畫面的版面與計算不變. 時間與速度兩組資料於軌跡顯示, 於規劃路徑不顯示.
  2. GPX 匯出內容依種類維持現行格式. 規劃路徑輸出具名航點與一條 <rte>, 軌跡輸出一條含時間的 <trk>. 理由為路徑檔的紀錄內容沒有改變.
